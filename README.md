# Jurni - Website đặt và quản lý tour du lịch

## Giới thiệu

Đây là **Đồ án chuyên ngành Công nghệ phần mềm** của nhóm **"Nước Dừa Code"**.

Mục tiêu: Xây dựng một website giúp người dùng **đặt tour du lịch** và **quản lý thông tin tour** một cách tiện lợi.

Website được xây dựng theo kiến trúc **Client-Server** với frontend React và backend Node.js.

---

## Tính năng chính

- Tìm kiếm và đặt tour du lịch
- Quản lý giỏ hàng, thanh toán trực tuyến (VNPay/MoMo)
- Xem và đánh giá tour đã tham gia
- Quản lý tài khoản cá nhân
- Chat real-time với hỗ trợ viên
- Bảo mật và phân quyền với Clerk
- Admin dashboard

---

## Tech Stack

### Frontend
React 18.3+ | Vite | React Router | TailwindCSS | Clerk | Socket.io | Axios

### Backend
Node.js | Express | Sequelize | MySQL 8.0+ | Clerk | Socket.io | Cloudinary

---

## Quick Start

```bash
# Backend
cd backend
npm install
npm run dev          # http://localhost:5000

# Frontend
cd frontend
npm install
npm run dev          # http://localhost:5173
```

Chi tiết setup: Xem [DATABASE_SETUP.md](./DATABASE_SETUP.md)
